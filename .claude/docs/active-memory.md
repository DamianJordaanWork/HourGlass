## Fix (2026-08-11 — dev-only sql.js Vite ESM-interop white-screen regression)
- **Symptom:** `npm run dev` (http://localhost:1420) white-screened — blank `#root`. Console: `Uncaught SyntaxError: The requested module '/node_modules/sql.js/dist/sql-wasm-browser.js?v=…' does not provide an export named 'default'`. Found only by a **browser smoke test** — `npm run test` (Node/vitest via `createRequire`) and `npm run build` (Rollup CJS interop) both stayed green, so CI-style checks did not catch it.
- **Root cause:** sql.js is UMD/CJS; its browser entry (`dist/sql-wasm-browser.js`, selected by the package `exports.browser` field) only assigns `module.exports.default = initSqlJs` **at runtime**. F3 had added `optimizeDeps: { exclude: ['sql.js'] }` to `vite.config.ts`, so Vite served that CJS file raw and the browser's native ESM found no static `default` export → `main.tsx`'s module graph aborted. (The app's DB layer swallowed the failure via its localStorage fallback, so the shell sometimes half-rendered, masking the boot break further.)
- **Fix:** in `vite.config.ts`, replaced `optimizeDeps.exclude: ['sql.js']` with `optimizeDeps.include: ['sql.js']`, so esbuild pre-bundles sql.js and synthesizes the interop `default` export. `import initSqlJs from 'sql.js'` now resolves in dev; network confirmed the dev server serves `/node_modules/.vite/deps/sql__js.js` (200) instead of the raw CJS file. No persistence logic or import statements changed. `test.server.deps.inline: ['sql.js']` (Node path) and the `?url` wasm import both left intact.
- **Verified:** typecheck green; `npm run test` 257/257 green; `npm run build` green (emits `sql-wasm.wasm`). Browser smoke test on a fresh tab: console **clean** (zero errors), `#root` mounts (children > 0), app shell renders (5 views + Demo badge + seeded work items); Insights shows "By task", Settings→Calendars shows Microsoft/Google/ICS, Ctrl/Cmd+K palette opens and Esc closes. (Screenshots unavailable — Browser pane not composited; DOM/console/network assertions used as proof instead.)
- **Lesson (done = smoke-tested):** vitest + `vite build` passing did **not** catch a Vite **dev** ESM-interop failure — different module resolution paths (createRequire / Rollup vs. dev-server native ESM). Browser smoke-testing the dev boot is part of "done" for anything touching bundler/dep-interop config. See ADR-014 correction note.
